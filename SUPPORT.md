# Support

- **Questions and ideas:** open a GitHub Discussion or an issue labelled `question`.
- **Bugs:** open an issue with your DataGhost version, Node.js version, the command or code you ran, and a small **fictional** dataset that reproduces the problem. Never attach real personal data.
- **Security issues:** follow [SECURITY.md](SECURITY.md) instead of opening an issue.

DataGhost is maintained by Workfonic Labs on a best-effort basis. There is no paid support or service-level agreement.
