# @workfonic/dataghost-generators

The seeded random number generator and the generator registry behind DataGhost: 57 generators for personal, professional, technical, numeric, temporal and custom values, all fictional or from reserved ranges.

Most users should install the SDK, [`@workfonic/dataghost`](https://github.com/abhisarena-sketch/ghostdata/tree/main/packages/core), which re-exports what you need from this package.

See the [DataGhost repository](https://github.com/abhisarena-sketch/ghostdata) for documentation. License: MIT.
