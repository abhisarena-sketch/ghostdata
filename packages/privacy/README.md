# @workfonic/dataghost-privacy

DataGhost privacy building blocks: heuristic sensitive-field detection with confidence and uncertainty, transformations (redact, pseudonymize, format-preserve, synthesize, generalize, null) and a safety scan for real-looking values. Detection is not a guarantee of protection.

Most users should install the SDK, [`@workfonic/dataghost`](https://github.com/abhisarena-sketch/ghostdata/tree/main/packages/core), which re-exports what you need from this package.

See the [DataGhost repository](https://github.com/abhisarena-sketch/ghostdata) for documentation. License: MIT.
